Splay

Splay 是一个基于 BST (Binary Search Tree 二叉搜索树) 的动态数据结构。 Splay 所操作的对象必须要有 且 严格弱序（可以计算排名）。 它支持以均摊单次 的时间复杂度进行如下操作：

  1. insert(x) 插入一个元素，以 为 。
  2. erase(x) 删除 的元素。
  3. find(x) 查找值为 的元素的信息。
  4. at(k) 查找排名第 的元素的信息。
  5. range(l, r) 提取出排名在 的区间
  6. merge(tr) 将另外一颗 splay 树拼接到这颗 splay 树上。 要求：若要将 merge 到 ，必须满足 或者

性质

假设现在 Splay 维护了一个有序的序列，以 为关键字。 这里，给出 Splay 的几条性质：

  1. Splay 树上的每一个节点都代表原序列中的一段区间。
  2. Splay 树上的每一颗子树都是 Splay 树。
  3. Splay 树的中序遍历就是排好序的原序列。
  4. Splay 树支持缓存，即访问越频繁，访问速度越快。
  5. Splay 不支持可持久化。
