Weight Balance Leafy Tree

发布于 2026-01-08 更新于 2026-09-23 学习记录

介绍一个时间复杂度比非旋 Treap 更优，更稳定，不依赖随机数的算法，WBLT。

什么是 WBLT？

Weight Balanced Leafy Tree，是根据 Weight 平衡的，信息记录在 Leafy Nodes 上的树。讲人话就是一颗平衡线段树。大概结构就是这样：

graph TD
  A("1<br/>w=3,sum=9") --> B("2<br/>w=3,sum=9") --> C["3<br/>w=1,sum=3"]
  B --> D["4<br/>w=1,sum=2"]
  A --> E["5<br/>w=1,sum=4"]
  1. 可以看到，其实 𝑤 就代表当前节点子树内有多少个叶子节点。
  2. 我们发现，WBLT 是满二叉树。
  3. WBLT 的 Non Leafy Node 的左右子树都是 WBLT。
  4. 我们定义一个 WBLT 是 Balanced，当且仅当对于任意一个非叶子节点都有 min(𝑤𝑙,𝑤𝑟)𝑤 ≥𝛼。原论文指出 𝛼 ∈[211,1 −√22] 可以保证时间复杂度是正确的，显然 𝛼 =14 是一个再好不过的选择了。

它支持什么？

  1. 区间操作（加、乘、懒标记等）
  2. 区间查询（和，矩阵乘积等）
  3. 区间复制
  4. 可持久化

时间复杂度：O(𝑛log⁡𝑛)
空间复杂度：O(𝑛)

可以看出，几乎就是一个时间复杂度完全正确的，和 FHQ Treap 没什么两样的平衡树，甚至！比 FHQ Treap 还好写！！！
